Необходимо спроектировать синхронный восьмиканальный регистровый файл разрядностью 8 бит с двумя независимыми асинхронными портами чтения и одним синхронным портом записи для использования в составе однотактного процессора. Модуль должен иметь следующие порты ввода-вывода: вход тактового сигнала clk, вход асинхронного сброса rst_n с активным низким уровнем, однобитный вход разрешения записи write_enable, трехбитный вход адреса записи wr_addr, восьмибитную шину входных данных wr_data, трехбитные входы адресов чтения rd_addr_0 и rd_addr_1, а также восьмибитные выходные шины данных rd_data_0 и rd_data_1. Внутреннее состояние памяти должно быть реализовано в виде массива rf из восьми 8-битных элементов типа logic. По сигналу асинхронного сброса rst_n все ячейки памяти модуля должны одновременно инициализироваться нулевыми значениями. Запись входных данных wr_data в ячейку по адресу wr_addr должна происходить строго по переднему фронту тактового сигнала posedge clk при условии, что флаг write_enable равен единице. В модуле должно быть жестко реализовано аппаратное правило нулевого регистра, согласно которому ячейка с адресом ноль всегда возвращает стабильный логический ноль, поэтому любая попытка записи данных по адресу 3'b000 должна игнорироваться схемой. Выходные порты чтения rd_data_0 и rd_data_1 должны работать полностью асинхронно в комбинаторной логике, мгновенно выставляя на соответствующие шины значения из массива rf по указанным адресам rd_addr_0 и rd_addr_1 в рамках того же тактового цикла, при этом при подаче нулевого адреса на любой из портов чтения выходная шина должна аппаратно коммутироваться напрямую на землю схемы в обход массива триггеров во избежание появления защелок и накопления мусорных значений из-за аппаратных помех реального кремния.
